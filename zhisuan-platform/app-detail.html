能力说明

4 项核心能力 · 全部结论支持引用溯源

条款风险识别

覆盖权责对等、违约责任、付款条件等 32 类风险条款，逐条给出风险等级与修订建议。

模板逐条比对

与标准模板按条款粒度对齐，标注缺失、新增与实质性偏离，输出条款级偏离度。

审查台账输出

一键导出审查台账（Excel / Markdown），含条款定位、风险等级、处理状态与责任人。

引用溯源

每条结论回链到合同原文段落与知识库依据，可点开查看上下文，避免“只给结论不给出处”。

API 调用入口

OpenAPI v2
调用示例 · curl
curl -X POST https://api.zhisuan.local/v1/apps/legal-contract-review/invoke \
  -H "Authorization: Bearer $ZS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "version": "v2.3",
    "input": {
      "contract_url": "https://oss.local/contracts/HT-2026-0912.pdf",
      "template_id": "TPL-采购-标准版"
    },
    "stream": false
  }'

限流 60 RPM / 单租户 8 并发；超出返回 4290，请按 Retry-After 退避重试。批量任务改用 callback_url 异步回传。

请求字段
字段类型说明
contract_urlstring必填。合同地址，支持 PDF / DOCX，单文件 ≤ 50MB
template_idstring必填。标准模板编号，如 TPL-采购-标准版
versionstring选填。应用版本，默认 v2.3
streamboolean选填。是否流式返回，默认 false
callback_urlstring选填。异步回调地址，批量任务使用
响应字段
字段类型说明
trace_idstring链路 ID，可在消耗回执中下钻到工具调用链路
statusstringsucceeded / partial / failed
usageobject输入与输出 Token 用量，用于对账
ledger_idstring结算单号，对应一条消耗回执
result.risks[]array风险条款清单，含等级、原文定位与修订建议
result.ledger_urlstring审查台账下载地址，有效期 7 天
错误码
错误码说明处理建议
4001额度不足 项目可用 Token 小于本次预估，请求被拦截。请充值或在控制中心申请追加额度；缺口量与当前水位见右侧账板
4003参数非法缺少必填字段，或 template_id 不存在；按请求字段表校验后重试
4010未授权API-Key 失效或应用未授权给该租户；重建密钥或提交授权申请
4290触发限流超过 60 RPM 或 8 并发；按 Retry-After 退避重试
4480文件解析失败合同损坏、加密或超出 50MB；转码为可解析 PDF 后重试
5001模型服务异常推理实例不可用，平台已自动切流；持续失败请提交工单
