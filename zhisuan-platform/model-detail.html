Qwen3-32B-Instruct 是平台当前的主力通用指令模型。320 亿稠密参数、128k 上下文窗口，在中文长文理解、报告撰写、条款比对与多轮工具调用上表现稳定；对 JSON Schema 强约束输出的遵循度高，可直接作为智能体的规划与汇总节点。

平台以 OpenAI 兼容协议暴露服务，无需改动既有 SDK 即可接入；权重以 safetensors 格式托管，支持按项目授权而非下载分发，租户只能通过推理服务调用，不能获取权重文件（MOD-003）。

计费按输入 / 输出 Token 分离计量，单价来自 Token 银行费率接口；每次调用返回 usage 字段，与账板、回执同源，可逐笔核对。

调用示例

OpenAI 兼容协议 POST /v1/chat/completions
curl · 基础对话
curl https://api.zhisuan.local/v1/chat/completions \
  -H "Authorization: Bearer $ZS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3-32b-instruct",
    "messages": [
      {"role": "system", "content": "你是企业知识问答助手"},
      {"role": "user", "content": "总结这份合同的风险条款"}
    ],
    "temperature": 0.3,
    "max_tokens": 1024,
    "stream": false
  }'
Python · OpenAI SDK 直连
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zhisuan.local/v1",
    api_key=os.environ["ZS_API_KEY"],
)

resp = client.chat.completions.create(
    model="qwen3-32b-instruct",
    messages=[{"role": "user", "content": "总结这份合同的风险条款"}],
    temperature=0.3,
    max_tokens=1024,
)

print(resp.choices[0].message.content)
print(resp.usage.total_tokens)   # 逐笔可核对
