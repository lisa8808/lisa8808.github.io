# 纯静态展厅 Demo 审计报告

## 结论

`shrek` 是可直接双击 `index.html` 运行的纯静态展厅 Demo。

运行时仅包含浏览器前端资源，不启动后台进程，不监听本地端口，不访问公网，不调用 AI API，不调用 CAD Runtime，也不执行 STEP 转换。

重新审计结论：复制完整目录并保持相对目录结构后，可从任意本地路径离线运行；目录名称、盘符和上级路径不影响 Demo。

## 静态能力

- 三个 STL 预置修改场景
- 三个 STEP 预置修改场景
- 一个 Creo ASM 预置装配修改场景
- Before/After、四视图、历史版本
- 装配清单、组件高亮和爆炸进度
- 浏览器本地 CSG、工程估算、SVG/PDF 导出
- localStorage/sessionStorage 本地状态模拟

## STEP 边界

STEP 源文件仅用于触发展厅场景。页面按文件名匹配内置 GLB：

- `Z250A-2-12A-轴承座-零件图.step`：修改孔距、新增倒角
- `Z250B-1-7A-工作台板-零件图.step`：开侧边槽

非预置 STEP 不执行解析，只显示展厅版支持范围提示。

## 安全边界

- Content Security Policy 设置 `connect-src 'none'`，浏览器禁止网络/API连接。
- Content Security Policy 设置 `worker-src 'none'`，浏览器禁止 Worker。
- 无 fetch、XHR、WebSocket、EventSource 或 Service Worker。
- 无 `.cmd`、`.ps1`、`.wasm`、`.exe`、`.dll` 或后台脚本。
- 无 localhost、127.0.0.1、AutoTest 或原工作区运行引用。
- 所有页面、脚本、样式、图片、视频和模型引用均为目录内相对路径，无缺失资源。

模型配置中的 API 地址、CAD 联动和授权中心是保留的产品概念界面，只写入浏览器存储，不发起连接。

## 移植要求

- 必须复制完整 `shrek` 目录，不能只复制三个 HTML 文件。
- 必须保留 `assets/`、`source-files/` 和页面文件之间的相对目录结构。
- 目标计算机需要支持 WebGL、`file://` 本地资源和浏览器存储的现代桌面浏览器。
- Demo 的设计记录和登录状态存放在目标浏览器的 localStorage/sessionStorage 中，不随目录复制迁移。
