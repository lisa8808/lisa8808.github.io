# 默认零件图源文件

此目录随 Demo 一起迁移，作为展厅上传演示的默认源文件路径。

## 通用建模

- `general/Z250B-4-11-螺纹套-零件图.stl`：修改孔径
- `general/Z250B-1-6D-中导板-零件图.stl`：开中心贯穿槽
- `general/Z250B-1-9-左打棒座-零件图.stl`：新增凸台
- `general/Z250A-2-12A-轴承座-零件图.step`：修改孔距、新增倒角
- `general/Z250B-1-7A-工作台板-零件图.step`：开侧边槽

## 原生精密

- `precision/z250-2-0.asm.6`：增加曲轴轴径

## 使用方式

1. 双击 Demo 根目录的 `index.html`。
2. 进入项目工作台。
3. 选择通用建模或原生精密模式。
4. 点击上传区域并从本目录选择对应文件。

浏览器安全策略不允许网页未经授权自动读取本地目录，因此需要在文件选择器中确认文件。STEP 场景只根据默认文件名加载已经内置的 GLB，不执行运行时 STEP 转换。
