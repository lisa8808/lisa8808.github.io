# 算力资源管理 · 前端界面

华鲲元启「算力中心 → 算力管理」的静态原型页面，单文件实现（HTML + CSS + 原生 JS，无构建、无依赖）。

## 预览

直接打开本目录下的 `index.html`，或将本目录作为静态站点根目录部署。

## 目录结构

```
算力统计/
├── index.html    # 页面本体（样式与脚本内联，无外部依赖）
├── README.md     # 本文档
└── .gitignore
```

## 页面结构

- **基础信息**：CPU信息（厂商 / 型号 / 数量 / 当前使用）、显卡信息（8 张 910B2，表格限高滚动、吸顶表头）
- **应用分析**（分组级时间范围：最近 1/7/30/90 天 + 自定义，一次驱动全部子模块）
  - 模型占用分析：堆叠柱（各模型显存）+ 总占用折线，柱顶数值 + 均值参考线
  - 任务占用分析：堆叠柱（推理 / 训练 / 评估）
  - AI Core 使用、CPU 使用（图 / PID 明细切换）
  - 内存使用（图 / PID 明细切换）
  - 磁盘分析：IOPS、带宽、时延、耗时、队列数 五个维度
  - 网络分析：带宽使用、丢包率

## 说明

- 图表全部为运行时用 SVG 绘制，随容器尺寸自适应重绘，支持悬停十字线与数据提示。
- 数据为演示用示例值，接入真实接口时替换 `CHARTS` 配置中的 `values` 即可。
