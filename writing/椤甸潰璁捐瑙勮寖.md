# 智能办公应用 UI 设计规范

> 版本：1.1  
> 基准页面：合同审查详情页  
> 适用范围：合同审查、文档分析、知识库问答、智能办公助手及相似的三栏工作台项目

## 1. 设计原则

1. **信息优先**：界面以文件、对话和结果为核心，不使用无业务意义的装饰。
2. **层级清晰**：通过字号、字重、颜色和间距建立层级，不依赖过多卡片嵌套。
3. **状态明确**：默认、悬停、按下、选中、禁用、加载和失败状态必须可区分。
4. **操作稳定**：动态内容不得引起布局跳动；按钮、图标和列表行使用固定尺寸。
5. **跨项目一致**：颜色、字号、圆角、间距及交互时间统一使用设计 Token。
6. **自适应布局**：桌面端使用弹性三栏，窄屏切换为纵向布局，不对整页同比缩放。

## 2. 基础设计 Token

### 2.1 字体族

```css
font-family: "PingFang SC", "Microsoft YaHei", Arial, sans-serif;
```

- 中文优先使用苹方。
- Windows 环境回退到微软雅黑。
- 数字和英文可使用 Arial 回退。
- 页面不使用负字距；默认 `letter-spacing: 0`。

### 2.2 颜色 Token

| Token | 色值 | 用途 |
|---|---:|---|
| `color-primary` | `#025DFF` | 主题色、选中状态、链接、加载状态、数字强调 |
| `color-primary-hover` | `#EEF4FF` | 蓝色控件悬停背景 |
| `color-primary-soft` | `#EAF2FF` | 选中项、用户消息、激活模块背景 |
| `color-primary-pressed` | `#DFEAFF` | 按下状态背景 |
| `color-heading` | `#18202E` | 栏目标题、重要标题 |
| `color-title` | `#0D162A` | 页面主标题、项目标题 |
| `color-text` | `#333333` | 正文、列表标题、快捷问题、消息文字 |
| `color-text-secondary` | `rgba(0, 0, 0, 0.60)` | 次要说明、分组标题、辅助信息 |
| `color-text-tertiary` | `#999999` | 日期、弱提示、非重点信息 |
| `color-placeholder` | `rgba(0, 0, 0, 0.40)` | 输入框占位文字 |
| `color-border` | `#E8EDF4` | 面板分割线、通用边框 |
| `color-border-control` | `#DCDCDC` | 按钮、输入类控件边框 |
| `color-background` | `#F6FAFE` | 页面画布背景 |
| `color-surface` | `#FFFFFF` | 顶栏、面板、输入框背景 |
| `color-surface-soft` | `#F7F8F8` | 列表悬停、选中记录背景 |
| `color-disabled-bg` | `#EFEFEF` | 禁用模块背景 |
| `color-disabled-text` | `#919191` | 禁用文字和图标 |
| `color-success` | `#22A35A` | 完成、成功状态 |
| `color-danger` | `#F04438` | 失败、风险、错误状态 |
| `color-user-message` | `#ECF2FE` | 用户消息气泡背景 |

### 2.3 阴影

| 名称 | 参数 | 用途 |
|---|---|---|
| 顶部导航阴影 | `0 4px 12px rgba(0,0,0,.08)` | 固定顶栏 |
| 输入框轻阴影 | `0 4px 12px rgba(0,0,0,.03)` | 对话输入框 |
| 激活控件阴影 | `0 4px 12px rgba(2,93,255,.08)` | 激活模块、工具按钮 |

阴影用于表达层级，不作为纯装饰。普通列表行和页面分区不添加浮层阴影。

### 2.4 圆角

| 尺寸 | 用途 |
|---:|---|
| `4px` | 图标按钮、复选框、更多按钮 |
| `6px` | 次级按钮、文件行、用户菜单 |
| `8px` | 输入框、提示消息、Toast |
| `10px` | 上传区、快捷问题、功能模块、记录行、消息气泡 |
| `13px` | 发送按钮胶囊 |

业务工作台避免使用超过 `10px` 的大圆角卡片。

### 2.5 间距

采用 4px 基础网格，优先使用：

```text
4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 px
```

| 场景 | 建议值 |
|---|---:|
| 图标与文字 | `5–10px` |
| 同组控件 | `8–16px` |
| 面板内边距 | `20px` |
| 对话正文左右边距 | `40px` |
| 三栏间距 | `20px` |
| 移动端页面边距 | `12px` |

## 3. 字体层级

### 3.1 字体层级表

| 层级 | 字号 / 行高 | 字重 | 颜色 | 使用场景 |
|---|---|---:|---|---|
| 页面主标题 | `20px / 28px` | `500–600` | `#0D162A` | 项目名称、核心页面标题、欢迎态标题 |
| 面板标题 | `16px / 26px` | `500` | `#18202E` | 合同、参考来源、对话、结果、生成模式等三栏主标题 |
| 标签与功能标题 | `14–16px / 24px` | `500–600` | `#18202E` | 页签、功能模块、用户消息 |
| 列表标题 | `15px / 22–24px` | `400–500` | `#333333` | 文件列表、知识库列表、生成记录、定稿文件 |
| 正文 | `14px / 26px` | `400` | `#333333` | 摘要、说明性长文本 |
| 常规 UI 文字 | `14–15px / 22–24px` | `400–500` | `#333333` | 按钮、快捷问题、分组名称、对话区文案 |
| 辅助信息 | `14px / 20–22px` | `400` | `rgba(0,0,0,.60)` | 文件数量、知识库数量、状态说明 |
| 弱信息 | `14px / 20px` | `400` | `#999999` | 日期、时间、次要元数据 |

### 3.2 字体使用规则

- 同一列表中的标题必须保持同一字号和行高。
- 文件列表项标题统一使用 `15px`；分组标题（如上传文件、历史文件、生成记录）统一使用 `14px / 22px / 500 / rgba(0,0,0,.60)`。
- 对话区消息、欢迎说明与快捷入口文案统一使用 `15px`，长文本行高不得低于 `24px`。
- 页面主标题只用于当前页面或项目名称，不用于卡片和面板内部的小标题。
- 状态文案可改变颜色，但不通过增大字号制造强调。
- 超长列表标题使用单行省略：

```css
white-space: nowrap;
overflow: hidden;
text-overflow: ellipsis;
```

## 4. 页面布局规范

### 4.1 顶部导航

- 高度：`62px`
- 背景：`#FFFFFF`
- 左内边距：`16px`
- 右内边距：`43px`
- Logo：`238 × 48px`
- 用户头像：`40 × 40px`
- 层级：`z-index: 5`
- Logo 可点击返回项目首页。

### 4.2 三栏工作台

- 面板顶部：`91px`
- 面板底部：`20px`
- 面板间距：`20px`
- 左右栏使用弹性宽度：

```css
--side-width: clamp(240px, calc(30.6vw - 138px), 450px);
```

- 中栏占据剩余空间，最优先保证对话内容可读性。
- 左栏用于文件和知识库，中栏用于对话，右栏用于结果和记录。
- 面板背景统一为 `#FFFFFF`。
- 面板标题区高度：`52px`，底部使用 `1px #E8EDF4` 分割线。
- 对话面板标题栏默认只保留左侧标题，不放置右侧辅助说明文字，除非有明确业务状态需要展示。

### 4.3 响应式断点

| 屏幕宽度 | 布局规则 |
|---:|---|
| `> 1200px` | 弹性三栏，左右栏按公式变化 |
| `1001–1200px` | 左右栏固定 `190px`，功能模块改为单列 |
| `≤ 1000px` | 三栏改为纵向分区，页面纵向滚动 |
| `≤ 520px` | Logo 缩至 `174px`，隐藏用户名和已选来源说明 |

禁止通过 `transform: scale()` 对整页同比缩放。

## 5. 组件样式规范

### 5.1 面板标题栏

```text
高度：52px
内边距：13px 20px 0
字号：16px
行高：26px
字重：500
颜色：#18202E
```

三个主面板标题必须保持完全一致。

### 5.2 上传区 / 添加知识库区

```text
高度：100px
左右边距：20px
边框：1px rgba(192,192,192,.30)
圆角：10px
背景：rgba(232,232,232,.30)
图标：30 × 30px
文字：14px / 22px
```

状态：

| 状态 | 边框 | 背景 |
|---|---|---|
| 默认 | `rgba(192,192,192,.30)` | `rgba(232,232,232,.30)` |
| Hover | `#9AB8FF` | `#F4F7FF` |
| Pressed | `#025DFF` | `#EAF1FF` |

### 5.3 文件列表行

```text
高度：48px
内边距：8px 0 8px 8px
圆角：6px
文件图标：24 × 24px
复选框：16 × 16px
标题：15px / 22px / #333333
```

- 标题超长时单行省略。
- 整行可点击选中或取消。
- 支持键盘 Enter 和 Space 切换。
- 行内复选框必须与分组标题行右侧的“全选”复选框右边界对齐。
- Hover 出现的删除操作放在复选框左侧；复选框始终保留在最右侧。
- Hover 背景：`#F7F8F8`。
- Pressed 背景：`#EDF3FF`。

### 5.4 次级操作按钮

适用于“纳入知识库”“选择知识库”“保存为笔记”。

```text
高度：32–38px
边框：1px #DCDCDC
圆角：6px
水平内边距：10–18px
图标：16–18px
字重：400–500
```

状态：

- Hover / Active：文字 `#025DFF`，边框 `#9AB8FF`，背景 `#EEF4FF`。
- Pressed：边框 `#025DFF`，背景 `#DFEAFF`。
- 按下缩放最多 `0.98`，避免明显跳动。

### 5.5 快捷问题按钮

```text
高度：44px
背景：#F7F7F7
圆角：10px
内边距：10px 14px 10px 16px
文字：15px / 24px / #333333
箭头：21 × 20px
图文间距：14px
```

- Hover：背景 `#EEF4FF`，整体右移 `2px`。
- Pressed：背景 `#DFEAFF`。
- 文案超长时省略，箭头不可被压缩。

### 5.6 用户消息气泡

```text
最小高度：50px
最大宽度：容器宽度 - 80px
背景：#ECF2FE
边框：1px #EEF1FF
圆角：10px
内边距：15px 16px
文字：15px / 18px / #333333
对齐：右侧
```

对话区消息文字统一采用 `15px`，以保证欢迎态、用户消息、助手消息与快捷入口的一致性。

### 5.7 助手正文

```text
字号：15px
行高：26px
颜色：#333333
左右边距：40px
```

摘要型长正文使用 `14px / 26px / #333333`。

### 5.7.1 欢迎态内容区

适用于对话区空状态或初始引导模块。

```text
整体位置：桌面端可使用 `transform: translateY(-92px)` 上移；低高度屏幕可取消偏移
标题：20px / 28px / 500 / #0D162A
说明文案：15px / 26px / #333333
标题到说明文案间距：16px
说明文案到操作图标组间距：18px
操作图标组到快捷入口间距：20px
快捷入口文案：15px / 24px
```

- 欢迎态内容整体应左对齐，避免居中大段说明文字。
- 三个操作图标与快捷入口应跟随欢迎态内容整体位置移动，不能只移动标题或说明文案。
- 快捷入口按钮应保持固定高度与箭头固定尺寸，长文案单行省略。

### 5.8 对话输入框

```text
高度：66px
左右边距：40px
圆角：8px
边框：1px rgba(154,184,255,.50)
背景：#FFFFFF
输入文字：16px / 24px
占位文字：rgba(0,0,0,.40)
```

状态：

- 空内容：发送按钮禁用，透明度降低。
- 有文字或聚焦：边框 `#025DFF`，外发光 `0 0 0 2px rgba(2,93,255,.08)`。
- 发送按钮启用后使用品牌渐变，Hover 提高饱和度。

### 5.9 功能模块按钮

适用于合同审查、合同翻译、合同对比、合同生成，以及“快速 / 标准 / 深度”等生成模式入口。

```text
高度：64px
圆角：10px
内边距：视觉左边距 14px，视觉右边距 12px
图标：22 × 22px
箭头：16 × 16px
标题：14px / 24px / 500
```

用于“快速 / 标准 / 深度”等生成模式卡片时：

- 图标与文字作为一个整体放在卡片左侧，整体视觉左边距为 `14px`。
- 箭头放在卡片右侧，视觉右边距为 `12px`。
- 箭头与“图标 + 文字”整体垂直居中，不放在文字下方。
- 若卡片有 `1px` 边框，CSS 可使用 `padding: 8px 11px 8px 13px`，使实际视觉间距达到 `14px / 12px`。
- 模式图标可在视觉上向左微调 `2px`，但不得影响文字与箭头布局。

| 状态 | 规范 |
|---|---|
| Active | 背景 `#EAF2FF`，可使用品牌蓝图标 |
| Hover | 提升饱和度、上移 `1px`、添加轻阴影 |
| Disabled | 背景 `#EFEFEF`，文字 `#919191`，图标灰度化且不可点击 |

禁用功能不得仅依赖颜色，应同时使用 `disabled` 与 `aria-disabled="true"`。

### 5.10 页签

```text
高度：38px
字号：16px
行高：24px
间距：40px
```

- 默认颜色：`rgba(0,0,0,.60)`。
- Active：颜色 `#18202E`，字重 `600`。
- Active 下划线：`30 × 3px`，主题蓝，圆角 `2px`。
- Hover：文字主题蓝，背景 `#F4F7FF`。

### 5.11 生成记录 / 定稿文件列表

```text
普通行最小高度：66px
多状态行最小高度：86px
圆角：10px
内边距：8px 12px 8px 10px
图标列：30px
操作列：24px
列间距：10px
标题：15px / 24px / #333333
辅助信息：14px / 22px
```

状态色：

| 状态 | 色值 |
|---|---|
| 正在生成中 | `#025DFF` |
| 审查完成 | `#22A35A` |
| 处理失败 / 风险数 | `#F04438` |
| 日期时间 | `rgba(0,0,0,.60)` 或 `#999999` |

- Hover / Active 背景：`#F7F8F8`。
- Pressed 背景：`#E8F0FF`。
- 加载图标旋转周期：`0.9s linear infinite`。
- 生成记录分组标题与左侧“上传文件 / 历史文件”等分组标题保持一致：`14px / 22px / 500 / rgba(0,0,0,.60)`。

### 5.12 Toast

```text
位置：视口底部 28px，水平居中
背景：rgba(24,32,46,.94)
文字：#FFFFFF
内边距：10px 16px
圆角：8px
动画：180ms
```

Toast 默认展示约 `1500ms`，不阻断当前操作。

## 6. 交互状态规范

所有可点击组件至少包含以下状态：

| 状态 | 要求 |
|---|---|
| Default | 保持稳定尺寸和对齐 |
| Hover | 使用背景、边框或轻微位移反馈 |
| Pressed | 使用更深背景或 `0.94–0.99` 缩放反馈 |
| Focus | `2px solid rgba(2,93,255,.32)`，偏移 `2px` |
| Active / Selected | 使用主题蓝或浅蓝背景，并保留持久状态 |
| Disabled | 灰色、不可点击、禁用 hover 和 pressed |
| Loading | 图标动画与状态文字同时出现 |
| Success / Error | 使用语义色，并保留可读文字说明 |

动效时长建议：

```text
按下反馈：120ms
颜色 / 背景过渡：150–160ms
浮层 / Toast：180ms
```

## 7. 图标规范

- 优先使用统一 SVG 资产，不使用 Unicode 符号代替业务图标。
- 同一业务动作必须使用同一图标，例如复制、编辑、删除、图钉。
- 图标必须设置明确宽高，不使用 `width: auto`。
- 常用尺寸：`16 / 18 / 20 / 22 / 24 / 30px`。
- 禁用图标使用灰度和透明度处理，不修改源 SVG。
- 图标按钮必须提供 `title` 或 `aria-label`。
- 装饰性图标使用空 `alt`，信息性图标提供清晰替代文本。

---

## 8. 可访问性规范

- 所有按钮使用真实 `<button>`，导航使用 `<a>`。
- 复选列表支持键盘 Enter 与 Space。
- 禁用项使用原生 `disabled`，并补充 `aria-disabled`。
- 图标按钮必须有可读名称。
- Toast 使用 `role="status"` 和 `aria-live="polite"`。
- 焦点状态不得被移除，颜色对比需满足常规文字可读性。
- 颜色不能作为状态的唯一表达，需配合图标或文字。

## 10. 验收清单

- [ ] 三栏标题是否统一为 `16px / 26px / 500 / #18202E`。
- [ ] 面板标题栏是否为 `52px` 高，内边距是否为 `13px 20px 0`。
- [ ] 页面主标题是否为 `20px`，没有在小组件中滥用。
- [ ] 文件列表项标题是否统一为 `15px / #333333`。
- [ ] 左侧分组标题与生成记录分组标题是否统一为 `14px / 22px / 500 / rgba(0,0,0,.60)`。
- [ ] 对话区消息、欢迎说明与快捷入口文案是否统一为 `15px`。
- [ ] 正文行高是否不低于 `24px`。
- [ ] 生成模式卡片中“图标 + 文字”整体是否距左 `14px`，箭头是否距右 `12px` 且垂直居中。
